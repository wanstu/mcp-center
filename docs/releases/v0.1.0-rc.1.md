# v0.1.0-rc.1

首个 MCP Center Release Candidate。

## 已实现

- 首访创建管理员，后续关闭公开注册
- 管理员登录、Session、退出、修改密码
- MCP CRUD
- Streamable HTTP / stdio
- tools/list / tools/call / Probe
- Runtime Session Manager
- MCP 导入 / 导出
- MCP 上游代理 `/mcp/{id}`
- OAuth Authorization Code + PKCE S256
- OAuth Client 管理
- OAuth Token 主动撤销
- Static Access Credential：Bearer / 自定义 Header / Query（默认关闭）
- 工具调用 Audit Log
- Web 管理控制台
- CLI / Web 服务
- CLI 与 Web 版本可见

## 安全默认值

- Query Token 默认关闭
- Secret 只保存哈希
- Access Credential 原文只在创建时展示一次
- OAuth Token 绑定具体 MCP Resource
- OAuth Client 修改 / 删除会撤销已有授权
- Audit 不记录工具参数值和原始 Token
- 管理员改密后旧 Session 全部失效

## RC 已知限制

- 当前仍通过本地 `go.mod replace` 引用 `mcp-center-core` 与 `wails-desktop-kit`
- 两个 MCP Center 仓库目前没有配置 Git remote
- 首版只实现管理员账号，不开放普通账号管理
- 当前以 CLI + Web 控制台为主要交付形态

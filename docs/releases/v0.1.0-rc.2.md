# v0.1.0-rc.2

发布目标：可长期运行、可用于真实 MCP 接入测试的第二个 Release Candidate。

## 本次范围

- 导出格式收进“导出”菜单，减少顶部歧义
- 导入支持直接选择 JSON 文件
- MCP 编辑表单补全 HTTP Header 与 stdio Env
- Header / Env Secret 继续只保存 `${NAME}` 引用
- Center UI 移除 ADM 专属“默认包含”概念，同时保留底层兼容字段
- 新增上游密钥变量管理：本地随机主密钥 + AES-GCM 加密
- Core 支持宿主注入变量解析器，不依赖 Center 的密钥实现
- Static Access Credential Scope 与代理实际能力统一为 `mcp:*`
- 工作台新增 24h 调用量、错误数与最近错误
- MCP 服务增加运行时状态筛选
- 审计日志默认保留 30 天，可配置 1–3650 天并立即清理过期日志
- 修复 stdio Runtime Session 被创建请求 context 提前终止的问题

## 明确不进入 rc.2

- 普通账号管理
- 多租户 / Workspace 模型
- `mcp:read` / `mcp:call` / Tool 级细粒度 ACL
- MCP 市场、分组、Prompt / Resource 管理
- ADM 工程接入 Core
- Desktop 壳扩展

# v0.1.0-rc.3

发布目标：完成外部接入、OAuth 自测、MCP 启停和设置页收口，形成可用于长期联调的第三个 Release Candidate。

## 本次范围

- MCP 外部接入地址同时支持 `/mcp/{name}` 与 `/mcp/{id}`
- Name / ID 地址均支持 Static Credential 与 OAuth Resource 绑定
- MCP 服务支持启用 / 禁用；禁用后保留配置，但工具测试、Runtime、OAuth 与外部代理统一拒绝访问
- 工具测试根据 inputSchema 自动生成最小可用 JSON 示例
- 工具测试新增 Form / JSON 双模式，并按 MCP + Tool 恢复参数、模式和最后结果
- 设置页展示当前 Listen Address、External Base URL、Data Directory
- OAuth 新增端到端自测：临时 Client + PKCE → 浏览器授权 → Token → MCP tools/list → Refresh → Revoke → 自动清理
- 发布 smoke 纳入 OAuth Authorization Code + PKCE、Bearer MCP 访问、Refresh 与 Revoke
- OAuth smoke 使用独立 Go verifier 进程，避免 PowerShell 子脚本提前结束导致发布流程假成功
- OAuth 服务新增总开关；关闭后 Discovery / Authorize / Token / Revoke / OAuth 自测停用，Static Bearer / Header / Query 保持可用
- 系统设置更新支持局部字段更新，避免修改日志策略时意外重置 OAuth 状态

## 明确不进入 rc.3

- 普通账号管理
- 多租户 / Workspace
- `mcp:read` / `mcp:call` / Tool 级细粒度 ACL
- MCP 市场、分组、Prompt / Resource 管理
- 动态 OAuth Client Registration
- ADM 工程接入 Core
- Desktop 壳扩展

## 发布门槛

- `mcp-center`、`mcp-center-core`、`wails-desktop-kit` 工作区 clean
- Center / Core 全量测试通过
- Windows / Linux / macOS × amd64 / arm64 六平台构建成功
- Windows 最终二进制完成 HTTP MCP tools/list + tools/call
- Windows 最终二进制完成 OAuth authorize + PKCE + MCP + refresh + revoke
- Windows 最终二进制完成 stdio MCP tools/list + tools/call
- `SHA256SUMS.txt` 与 release manifest 生成成功
- manifest 记录 Center / Core / Kit 三个源码 commit
- 最终二进制 `--version` 返回 `v0.1.0-rc.3`

## 已知发布限制

- Center 当前仍通过本地 `go.mod replace` 引用 Core 与 Desktop Kit
- 当前仓库没有 Git remote，因此 RC 只能生成本地 tag / 本地发布目录
- 正式 `v0.1.0` 前应把 Core / Kit 依赖改成可复现的版本依赖，或明确采用统一 workspace / vendor 分发方案

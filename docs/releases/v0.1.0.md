# v0.1.0

MCP Center 首个正式版本。

## 正式版范围

- 首次访问创建管理员，后续关闭公开注册
- 管理员登录 / 退出 / 修改密码
- MCP Definition CRUD
- Streamable HTTP / stdio
- MCP Probe / tools/list / tools/call
- Runtime Session Manager：连接复用、缓存、刷新、断开、配置变更自动失效
- MCP 启用 / 禁用
- 外部 Endpoint 同时支持 `/mcp/{name}` 与 `/mcp/{id}`
- Static Access Credential：Bearer / Header / Query
- Authorization Code + PKCE S256 OAuth
- OAuth Metadata / Protected Resource Metadata
- OAuth Client 管理、Refresh、Revoke
- OAuth 服务总开关
- OAuth 端到端自测
- MCP Center / 通用 `mcpServers` 导入导出
- 导入冲突策略与原子预检
- 上游 Secret 变量与 AES-GCM 本地加密
- 工具测试 Form / JSON 双模式、Schema 示例、参数和结果恢复
- 调用审计、24h 汇总、最近错误、可配置保留时间
- 设置页显示 Listen / Base URL / Data Directory
- Windows / Linux / macOS × amd64 / arm64 CLI/Web 二进制
- 自包含、离线可验证的 source bundle
- 正式 Release smoke：HTTP / OAuth / stdio

## 依赖与构建

- `mcp-center-core` 保持独立项目边界
- Desktop Kit 固定使用 `v0.10.0`
- release source.zip 包含 Center、Core 和 vendor
- source.zip 必须在 `GOPROXY=off` 且隐藏 sibling Core 的条件下通过全量测试与构建

## 明确不属于 v0.1.0

- 普通账号管理
- 多租户 / Workspace
- Tool 级 ACL / 更细 Scope
- MCP 市场与分组
- Prompt / Resource 管理
- 动态 OAuth Client Registration
- SSO / LDAP
- Desktop 壳
- ADM 工程改动

ADM 接入不属于本项目发布动作；未来由 ADM 方自行接入 `mcp-center-core`。

## 发布门槛

- Center/Core 工作区 clean
- Center/Core 全量测试通过
- 六平台二进制构建成功
- HTTP MCP smoke 通过
- OAuth authorize + PKCE + MCP + refresh + revoke smoke 通过
- stdio MCP smoke 通过
- source bundle 离线测试与构建通过
- SHA256 全量复验通过
- release manifest / source manifest 完整

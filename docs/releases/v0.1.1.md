# MCP Center v0.1.1 发布记录

本版在 v0.1.0 的基础上纳入：

- 默认监听 0.0.0.0:8610，域名/IP Host 白名单默认关闭、可单独启用。
- OAuth 无独立开关，统一受 Host 白名单约束；Client / PKCE / Token 校验保留。
- 初始化管理员增加两次密码确认，以及一个统一的显示/隐藏按钮。
- Linux amd64/arm64 独立二进制及 .deb 安装包（Kit v0.10.2 systemd packaging）。
- systemd 专用低权限账户、安装后启用和启动、故障重启、升级已有服务、卸载保留数据。

## 安装

Debian 12 x86_64：

```bash
sudo apt install ./mcp-center-v0.1.1-linux-amd64.deb
sudo systemctl status mcp-center
sudo journalctl -u mcp-center -f
```

如安装的是候选版，请将文件名换成具体 RC 名称（例如 v0.1.1-rc.2）。

服务用户：mcp-center；数据：/var/lib/mcp-center；服务名：mcp-center.service。
首次安装自动启用 systemd 开机自启，监听 0.0.0.0:8610。
覆盖升级不删除已有账号、配置、密钥和数据库。卸载会停止服务但保留数据。

如果直接对公网开放，请先通过防火墙或反向代理保护首次初始化页面，
并优先使用 HTTPS。Host 白名单不限制访客来源 IP，也不替代用户登录或 OAuth。

## 已安装 Linux 系统服务的常用命令

```bash
# 查看开机自启状态、运行状态、配置的监听地址
mcp-center service status

# 修改监听端口（例如改为 8620），保存到 /etc/default/mcp-center
# 如果服务正在运行，会尝试重启；覆盖安装不会清除端口配置
sudo mcp-center service set-port 8620

# 设置是否随开机自启（与运行/停止相互独立）
sudo mcp-center service autostart on
sudo mcp-center service autostart off

# 手动控制服务
sudo mcp-center service start
sudo mcp-center service stop
sudo mcp-center service restart

# 查看实时日志和管理服务
journalctl -u mcp-center -f
sudo systemctl restart mcp-center
```

直接启动程序时，原有 `--listen`、`--data-dir`、`--base-url` 参数继续有效；
它们不会修改已安装 systemd 服务的持久配置。
安装包默认生成 `EnvironmentFile=-/etc/default/mcp-center`，
并通过 `MCP_CENTER_LISTEN` 覆盖默认 `0.0.0.0:8610`。

首次公开部署应先通过防火墙限制访问并完成管理员初始化。改变监听端口并不自动修改防火墙策略。

`set-port` 会检查服务文件是否引用 `/etc/default/mcp-center`，如果是旧版 RC.2 的固定启动配置，会提示先升级安装包，避免表面修改成功但实际上无效。

## 版本与构建约束

- MCP Center Source / Core Source 保持两个独立仓库。
- Kit packaging 必须使用 v0.10.2 tag 对应的 Git HEAD，发布工程记录该 commit。
- Center Go Module 可独立使用稳定 Kit v0.10.0；Linux 安装器由 Kit v0.10.2 的 CLI 生成。
- source bundle 的离线构建保证适用于 Center 程序；重新生成 .deb 需提供 Kit v0.10.2 打包器。
- 原先 v0.1.0 正式产物保持原样，不覆盖。

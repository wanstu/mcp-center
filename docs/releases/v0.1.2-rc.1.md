# MCP Center v0.1.2-rc.1 — Linux AppStream 元数据兼容修复

本 RC 在正式版 v0.1.1 的功能基础上，修复 Linux `.deb` 中 AppStream 元数据安装文件名：

- 修复前：`/usr/share/metainfo/mcp-center.metainfo.xml`（Debian 包名）
- 修复后：`/usr/share/metainfo/com.github.wanstu.mcp-center.metainfo.xml`（组件 ID）
- XML 内容中的 `<project_license>BSD-3-Clause</project_license>` 不变；
  完整 BSD 许可证仍随包安装到 `/usr/share/doc/mcp-center/copyright`。
- Kit 使用通用打包器 v0.10.3，校验 XML 结构与组件 ID。
- Center 与 Core Go 代码、登录、OAuth、MCP 和服务操作不因此更改。

## 测试与使用

Linux Debian / Ubuntu AMD64：

```bash
sudo apt install ./mcp-center-v0.1.2-rc.1-linux-amd64.deb
mcp-center --version
mcp-center service status
dpkg -L mcp-center | grep -E 'metainfo|copyright'
```

注意：GNOME Software 从**本地文件**打开 `.deb` 时，有时不能把 PackageKit
的本地包条目和系统的 AppStream 元数据关联起来，界面仍有可能显示“未知许可证”。
此次修复的是元数据的规范命名，并不声称修复 GNOME Software 所有版本的
本地安装显示行为。

首次安装页面的“由第三方提供／潜在危险”属于包来源或权限评估，
**不由许可证本身决定**，不会因为变更文件名而自动消失。

必须以完全安装结束后的页面观察，以及 `dpkg -L`、版权文件内容来分别判断。
本 RC 保持 /var/lib/mcp-center 下的业务数据，保留原来的 systemd 服务。

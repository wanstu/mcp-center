# MCP Center v0.1.2-rc.2 — Kit v0.11.3 统一升级

- Go Module 固定依赖 `github.com/wanstu/wails-desktop-kit v0.11.3`。
- Linux Debian 打包工具由相同 Go Module 运行 `cmd/desktopkit`，不再读取相邻 Kit 仓库的工作区。
- Go 发布清单同时记录 Kit module 版本和 Go module checksum，禁止使用不同版本的打包器。
- 复用 Kit `servicecontrol` 的 start/stop/restart/enable/disable，应用自身保留端口配置和 doctor。
- 顶层 CLI 支持 `mcp-center status`、`doctor`、`start`、`stop`、`restart`、
  `set-port <port>`、`autostart on|off`，以及显式前台 `serve`。
- 未知顶层命令直接报错，不尝试监听已运行的服务端口。
- 维持 `--listen` / `--data-dir` / `--base-url` 和旧的 `service` 子命令兼容。

## Debian 测试（旧包升级）

已验证 `v0.1.1-rc.2 → v0.1.2-rc.2` 的实际 dpkg
升级解包流程、数据文件和 `/etc/default/mcp-center` 中自定义端口保留。
BSD 许可证以及 AppStream 路径均可正确解包。
Kit v0.11.3 已有独立的真正 systemd 宿主 CI 验收记录；Center 自己的 systemd CLI
仍建议部署到测试 Debian 虚拟机后核对正常系统开机、状态、端口和重启。

## 操作

```bash
sudo apt install ./mcp-center-v0.1.2-rc.2-linux-amd64.deb
mcp-center status
mcp-center doctor
sudo mcp-center set-port 8620
sudo mcp-center autostart on
sudo mcp-center restart
```

改端口前确认新的防火墙规则允许访问。软件监听仍默认 `0.0.0.0:8610`，
Host 白名单独立启用，默认关闭。

若之前安装失败，先执行 `sudo dpkg --audit` 检查 dpkg 状态；升级成功后再核对服务。

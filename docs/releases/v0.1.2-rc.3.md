# MCP Center v0.1.2-rc.3 — CLI 帮助统一

基于 v0.1.2-rc.2，统一命令行帮助入口：

- `mcp-center -h`、`--help`、`help` 都输出完整命令说明。
- `mcp-center serve --help` 和带前台启动参数的 `-h` 也使用统一帮助。
- 帮助列出 `status`、`doctor`、`start`、`stop`、`restart`、
  `set-port`、`autostart`、`serve` 及全部支持的启动参数。
- 获取帮助不会创建监听端口，也不会修改已安装的服务。
- 原有 `--version`、`--listen`、`--data-dir`、`--base-url` 不变。
- Kit 依赖和 Linux Debian 打包器继续统一使用 `v0.11.3`。

RC.3 是 CLI 帮助和用户指引修复，不修改 MCP Center Core / Kit / ADM。
Debian 升级应保留原有 `/var/lib/mcp-center` 数据与端口配置。

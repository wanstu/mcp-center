# MCP Center v0.1.2 正式版

本版本将 Linux systemd 服务安装、统一 Kit 依赖、服务命令与 CLI 帮助完成正式收口。
发布范围以 v0.1.2-rc.3 已验证功能为准，不新增其他 MCP 协议或 UI 功能。

## 变更与使用

- Wails Desktop Kit 统一固定为 `v0.11.3`：Center Go Module 和 Linux Debian 打包器共用版本，
  发布清单记录版本及 Go checksum；不再依赖 Kit 目录的本地工作区状态。
- Debian 12 AMD64/ARM64 `.deb`：systemd 安装、自启、升级、卸载保留业务数据。
- 默认监听 `0.0.0.0:8610`；Host 域名/IP 白名单单独配置、默认关闭。
- 使用顶层命令 `status`、`doctor`、`start`、`stop`、`restart`、
  `set-port PORT`、`autostart on|off` 管理 Linux 服务。
- `mcp-center -h`、`--help`、`help`、`serve --help` 统一输出完整命令说明。
- 前台运行保持 `mcp-center serve [--listen ...] [--data-dir ...] [--base-url ...]`，
  同时兼容旧式无 `serve` 的直接运行参数。
- 无效顶层命令直接报错，不会意外再启一个占用 8610 的服务器。
- MCP Center 与 MCP Center Core 均使用 BSD-3-Clause 开源许可证。Debian 包带有
  `/usr/share/doc/mcp-center/copyright` 和 AppStream 元数据。桌面软件中心可能仍把
  本地 DEB 的许可证显示为“未知”；此项不阻碍服务运行。

## Debian 安装或升级

将对应安装包放在 Debian 本地目录：

```bash
sudo apt install ./mcp-center-v0.1.2-linux-amd64.deb
mcp-center --version
mcp-center -h
mcp-center status
mcp-center doctor
```

服务控制：

```bash
sudo mcp-center set-port 8620
sudo mcp-center restart
sudo mcp-center autostart on
sudo mcp-center stop
sudo mcp-center start
```

`set-port` 修改 `/etc/default/mcp-center` 中的监听端口，数据位于
`/var/lib/mcp-center`。安装升级不主动清空账户、密钥和数据库；
本地防火墙及反向代理需要单独适配新端口。

## 验收与发布边界

正式发布流水线：
1. Center/Core Go 全量测试。
2. Windows、Linux、macOS 的 AMD64/ARM64 二进制与 Linux DEB 构建。
3. 最终 Windows 二进制执行 CLI 帮助、HTTP MCP、OAuth PKCE/Refresh/Revoke、stdio MCP 冒烟测试。
4. 自包含源码 ZIP 在隐藏 Core 仓库、断网/vendor 条件下独立测试、编译。
5. 生成 SHA256SUMS.txt 与 release-manifest.json，独立复验哈希。
6. Debian 真实 dpkg 解包升级测试，核对许可证、端口及业务数据保留。

本地发布不等同于公开发布：Center/Core 当前没有 Git remote，Tag 仅保存在本地。
Kit v0.11.3 的 systemd 真实主机 CI 已完成，但 Center 仍需用户在实际 Debian 服务环境中
确认安装升级后 `status`/`doctor`、端口持久化以及开机重启表现。

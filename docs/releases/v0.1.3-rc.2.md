# MCP Center v0.1.3-rc.2（候选版）

本版本在 `v0.1.3-rc.1` 的多来源 MCP 导入基础上修复 ChatGPT OAuth Client ID 连接问题，并完善导入密钥管理。

## 改动范围

- OAuth Authorization Server Metadata 公开 `registration_endpoint`；新增 RFC 7591 `POST /oauth/register`，支持无需管理员预先创建 Client ID 的 OAuth 公共客户端。
- 限制注册为 public client、PKCE S256 授权，注册本身不会授予访问权限；增加限流和客户端数量上限。
- 授权页面同时展示客户端自报名称和真实 Redirect URI，用户继续登录并点击授权。
- 从 OpenCode、WorkBuddy、Claude Code、mcpServers 等导入 MCP 时，Header/env 明文变量在确认导入后自动加密存入 Center 密钥库。
- 自动变量名以 MCP 名称为前缀，并带稳定短哈希避免冲突，例如 `WM_TEST_DB_ENV_MYSQL_HOST_XXXXXXXX`。
- 预览、MCP 定义和常规变量列表不展示原始值；只保存所选项的变量。冲突不会静默覆盖，导入失败回滚新创建的变量。
- 上游密钥变量列表新增“查看值”功能（需管理员 Session，禁止缓存，关闭窗口清除值，并设置短暂自动关闭）。
- 保留原有管理员手动创建、修改和删除 OAuth Client 的功能。
- Go Module 与 Linux Debian 打包器继续统一使用 Wails Desktop Kit `v0.11.3`。

## 验收项目

- OAuth：动态客户端注册、元数据发现、用户同意、PKCE、Token 资源绑定、限流、非法回调拒绝。
- 导入：JSON/JSONC、选中项导入、自动保存变量、加密文件无明文、管理员查看、未授权拒绝、旧变量冲突/跳过、异常回滚。
- 前端：导入预览→确认、修改输入强制重新预览；语法检查和登录界面回归。
- Linux 旧版升级：核对 .deb 安装、数据保留、端口配置、systemd 元数据。
- 正式打包脚本：跨平台构建、OAuth/HTTP MCP/stdio 冒烟测试、离线 source ZIP 与 SHA256 校验。

## Debian 试用

使用 `dist/v0.1.3-rc.2/mcp-center-v0.1.3-rc.2-linux-amd64.deb`：

```bash
sudo apt install ./mcp-center-v0.1.3-rc.2-linux-amd64.deb
mcp-center --version
mcp-center status
mcp-center doctor
```

与 ChatGPT 连接时，请检查部署的公开 HTTPS 服务器：
`/.well-known/oauth-authorization-server` 返回 `registration_endpoint`，且 `issuer`、
`authorization_endpoint`、`token_endpoint` 均指向有效的外部 HTTPS 地址。
反代情况下可能需要设置 `--base-url` 为公开 HTTPS 根地址；仍需真实 ChatGPT 页面做端到端验收。

安全提示：密钥库 AES-GCM 加密文件不能直接查看明文，但是密钥文件位于同一数据目录。
如果攻击者复制密钥库和主密钥文件，仍可能恢复变量值，应通过 OS 权限、HTTPS 和备份管理保护该目录。

本候选版先本地验证，不自动推送 GitHub；不会修改 ADM、Core 或 Kit。

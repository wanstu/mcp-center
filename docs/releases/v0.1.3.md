# MCP Center v0.1.3 正式版

v0.1.3 重点完成远程 MCP 兼容、OAuth 动态客户端注册、反向代理适配、定时健康探测、协议诊断，以及正式 GitHub Actions 发布链路。

## 主要变更

- 支持 RFC 7591 动态 OAuth Client Registration，ChatGPT 等客户端可自动完成 Client 注册。
- 修复 HTTPS 反向代理下 OAuth Metadata、Secure Cookie 与公开协议判断。
- 修复经过本机反向代理时 Go MCP SDK localhost protection 导致的远程 discovery 403。
- 保留 tools/list 的 OpenAI 兼容 securitySchemes 元数据。
- 新增 MCP 协议诊断日志，覆盖 discovery / tools/list 等链路，同时避免记录 Token、参数和 Session ID 明文。
- 新增定时 MCP 健康探测，可配置启用、间隔、超时，并在管理 UI 展示最近/下次探测状态。
- MCP 导入支持 ADM 兼容配置预览、逐项选择以及 MCP 范围密钥加密。
- 关于页补齐版本、Commit、构建时间、Go、Kit 等诊断信息。
- MCP Center Core 固定使用 v0.1.1；本版本实际发布对应 Core commit 210e489c8ab4。

## 正式发布方式

从 v0.1.3 起，正式 GitHub Release 使用 GitHub Actions 构建：

1. Checkout Center release tag。
2. Checkout固定 Core tag。
3. 执行 Center/Core 测试、go vet 与 UI smoke。
4. 在 GitHub Windows Runner 运行完整 build-release.ps1。
5. 构建 Windows/Linux/macOS AMD64/ARM64 以及 Linux DEB。
6. 执行 CLI、HTTP MCP、OAuth PKCE/Refresh/Revoke、stdio MCP 与定时探测 smoke。
7. 生成 source ZIP、SHA256SUMS.txt、release-manifest.json。
8. 发布前再次校验 SHA256。
9. GitHub Release 已存在时拒绝覆盖附件；需要修复正式版本时必须发布新版本号。

正式 Release 不使用开发机 dist/ 中的二进制。

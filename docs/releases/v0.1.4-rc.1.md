# MCP Center v0.1.4-rc.1 发布说明

- 上游 MCP 新增旧版 SSE（Server-Sent Events）传输，保留 Streamable HTTP / stdio。
- 支持从 MCP 客户端配置中导入和导出 `type: "sse"`。
- 支持 SSE 上游的 Header 变量鉴权、健康检查、工具发现和调用。
- SSE 会话生命周期由 mcp-center-core 负责，避免外层 HTTP 请求结束时断开下游长连接。
- 统一 Go MCP SDK `v1.8.0`，使用 MCP Center Core `v0.1.2-rc.1`。
- 新增 SSE 的端到端与认证测试；其他已有传输保留兼容性测试。

部署注意：使用 GitHub Actions 对本 tag 生成的 Release 产物；升级前保留应用数据目录备份；此版本为 RC，不自动更新现网运行中的服务。

# MCP Center v0.1.4

基于 `v0.1.4-rc.1` 验收通过的 SSE 功能发布正式版。

- 支持旧版 MCP SSE 上游，保留 Streamable HTTP 与 stdio。
- 支持导入/导出 SSE 上游配置、Header 环境变量鉴权、工具发现与调用。
- 更新依赖至正式版 MCP Center Core `v0.1.2`；Go MCP SDK `v1.8.0`。
- 正式 CI 使用 Core `v0.1.2` tag，运行完整 Go 测试、静态检查、跨平台打包与 SHA256 校验。

升级：使用对应 GitHub Release 构建产物替换现有程序；保留并备份配置与数据。当前 RC 可平滑升级，仍由用户自行部署。

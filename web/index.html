创建 OAuth Client

首版使用 Public Client + PKCE，不生成 client_secret。

Redirect URI 必须精确匹配。公网地址要求 HTTPS；localhost / 127.0.0.1 等 loopback 地址允许 HTTP。

导入 MCP

参照 ADM：识别多个客户端配置，先预览并勾选，再确认导入。预览不会修改任何 MCP。

也可以直接粘贴客户端 MCP 配置
安全提示：预览不会显示密钥值，确认导入时自动加密保存生成的变量；已有同名变量的值不同时会提示冲突，不会覆盖。
